Same binary, real physics

On your machine, zron mujoco scene.xml drives any MuJoCo model through the bridge. Physics needs Python and MuJoCo, so it isn't in the browser; see the 68/68 compatibility matrix.

Run it for real

  • Install: download zronos-v1.1.1-linux-x86_64.tar.gz from Releases, or make && sudo make install.
  • zron new mybot scaffolds a robot; zron doctor checks it.
  • zron up mybot/robot.manifest runs it in real time; Ctrl-C or SIGTERM halts cleanly. A systemd unit is in contrib/.
  • Services are written in Robot Chalao; try the language in its own playground.
The browser build uses a virtual clock and the simulated HAL, exactly like zron demo. MIT · built by megazron.
